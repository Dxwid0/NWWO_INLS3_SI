# Code of Conduct - zasady postępowania[cite: 1]

1. Cel kodeksu:
Celem tego kodeksu jest zapewnienie przyjaznego, bezpiecznego i sprzyjającego współpracy środowiska dla wszystkich osób współtworzących projekt, niezależnie od ich doświadczenia czy poglądów.

2. Zasady współpracy:
* Okazuj szacunek i życzliwość innym członkom zespołu.
* Konstruktywna krytyka jest mile widziana, ale powinna dotyczyć kodu lub pomysłów, a nie osoby.
* Bądź otwarty na dyskusję i wymianę doświadczeń.

3. Niedopuszczalne zachowania
* Jakiekolwiek formy nękania, dyskryminacji lub obrażania innych uczestników.
* Celowe wprowadzanie złośliwego kodu lub psucie projektu.
* Ignorowanie uwag zespołu ds. bezpieczeństwa lub moderacji.

4. Code Review
* Każda zmiana w kodzie powinna przejść rzetelny przegląd przez co najmniej jedną inną osobę.
* Podchodź do recenzji z życzliwością – pomagaj autorowi kodu rozwijać jego umiejętności, zamiast go krytykować.
* Staraj się odpowiadać na zgłoszone uwagi w rozsądnym czasie.

5. Zgłaszanie naruszeń
* Jeśli zauważysz zachowanie naruszające ten kodeks, zgłoś to głównymmaintainerom projektu poprzez utworzenie prywatnego zgłoszenia (Issue) lub bezpośredni kontakt.
* Wszystkie zgłoszenia będą traktowane poufnie i z należytą powagą.

6. Konsekwencje naruszeń
* W zależności od stopnia naruszenia, konsekwencje mogą obejmować upomnienie, tymczasowe zawieszenie praw do kontrybucji lub trwałe zablokowanie dostępu do repozytorium.

**Współpraca, wzajemny szacunek i odpowiedzialność za własną pracę są podstawą rozwoju tego projektu**[cite: 1]
